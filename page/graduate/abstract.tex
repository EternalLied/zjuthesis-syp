\chapternonum{摘要}

% 近年来，深度学习在计算机视觉、自然语言处理、语音识别等众多领域得到了广泛应用。随着任务复杂性的增加，深度学习所使用的数据集规模和神经网络模型的复杂性也在不断提升。因此，单个设备的有限计算能力已经无法满足庞大深度学习任务的训练需求。为了应对这一挑战，分布式深度学习应运而生。它通过协同多个设备或计算节点，实现对大规模数据集和复杂模型的并行处理，从而提高训练效率。然而，在分布式深度学习的训练过程中，为了实现模型参数的一致性，计算节点之间需要频繁地进行模型参数或梯度的通信。因此，不合理的集群配置可能导致较高的通信延迟，从而使通信成为性能瓶颈，降低训练效率。为了有效分析分布式深度学习的性能瓶颈，以便更合理地配置集群规模，本文研究了训练时间预测方法。在此基础上，为了进一步降低分布式深度学习中的通信开销并提高通信效率，本文从参数同步拓扑优化和通信数据压缩两个方面展开了研究。本文的主要工作如下：

% （1）提出了一种面向一般拓扑的分布式深度学习训练时间预测方法。现有的训练时间预测方法主要基于简单的星形拓扑或环形拓扑，因而缺乏通用性。本文通过深入分析分布式深度学习中集合通信原语的底层机理以及不同参数同步拓扑的通信特征，建立了一种细粒度的通信时间预测模型，该模型适用于各种参数同步拓扑上的通信时间预测。其次，为了提高训练时间的预测精度，本文对计算时间预测模型引入了额外的特征，并根据计算与通信的并行性分析，建立了精细化的训练时间预测模型。实验结果表明，本文的方法能够以高于85\%的精度预测在不同拓扑上基于数据并行的分布式深度学习的训练时间。

% （2）提出了一种面向高效通信的参数同步拓扑优化方法。现有的参数同步拓扑很难有效平衡每次迭代的通信开销和迭代复杂度，导致分布式深度学习的训练效率相对较低。本文分别针对同构带宽场景和异构带宽场景设计了以一致性速度为优化目标的参数同步拓扑优化问题，并在优化问题中引入了通信相关的约束。然后，提出了基于ADMM算法和模拟退火算法的参数同步拓扑优化问题求解框架，用于高效地求解不同场景下的参数同步拓扑优化问题。实验结果表明，采用本文提出的方法得到的参数同步拓扑在一致性速度上优于现有的参数同步拓扑，并且能够使分布式训练算法在更短的时间内达到设定的测试准确率，从而提高训练效率。


% （3）提出了带宽自适应的量化分布式训练算法，BA-QDSGD和BA-QDSGT。在分布式训练中，由于拓扑中不同边的可用带宽存在差异，对所有节点采用相同的量化程度会导致通信资源浪费。为解决这一问题，本文设计了基于带宽矩阵的自适应策略，通过增加高带宽边上的量化比特数，减小了对应边上的通信数据量化误差。该策略在确保模型精度的同时，使各边的通信时间保持一致，从而提高了通信资源的利用率。随后，将带宽自适应策略与差分压缩以及压缩误差补偿技术结合，并应用于DSGD算法和DSGT算法，提出了BA-QDSGD算法和BA-QDSGT算法。实验结果表明，这两个算法能够在加快模型收敛速度的同时，保证模型的精度，从而提高训练效率。

近年来，深度学习在计算机视觉、自然语言处理与语音识别等领域持续扩展应用，模型规模与训练数据量不断增长，单设备算力与显存难以支撑大规模训练任务，多节点分布式训练逐渐成为主流方案。然而，节点规模扩大后，训练效率往往受限于通信与同步开销：梯度聚合、张量切分后的中间结果交换等操作会在每次迭代中反复进行，通信耗时逐步占据端到端训练时间的主要部分。与此同时，现代训练集群呈现多链路并行、层级互连与交换机结构复杂等特征，传统固定模板算法在通信轮数、链路利用率与调度灵活性方面逐渐暴露出瓶颈。围绕上述问题，本文从集合通信算法设计、面向物理拓扑的集合通信调度合成以及张量并行下的计算通信并行三个层面展开研究，以提升分布式训练的通信效率与整体吞吐。本文主要工作如下：

（1）设计并实现了面向双向并行环形互连的双半环集合通信算法。针对双向链路可并行传输的物理系统，本文在双向 Ring 的基础上重组通信流程，通过链路聚合减少有效通信轮数，并给出 AllGather、ReduceScatter 与 AllReduce 的统一实现方式。在昇腾 910C 集群上基于 HCCL 完成实现与评估，结果表明在不同的节点数与数据量配置下，双半环算法相对双向 Ring 的算法带宽提升约 2.7\%–33.1\%，在不同规模下均能取得稳定收益。

（2）构建了面向多级交换机拓扑的集合通信算法合成方法 FTACAS。针对包含交换机节点与端口并发约束的真实互连环境，本文以时间扩展网络为建模基础，统一刻画设备/交换机节点、链路带宽与时延以及转发机制，并在此之上设计事件驱动的贪心合成框架，支持 AllGather 与 AlltoAll 算子的调度自动生成。对多种典型 GPU 集群拓扑的实验结果表明，FTACAS 在算法带宽上整体不弱于对比基线TECCL，在部分复杂拓扑上 AllGather 可达到基线的 1–3 倍；AlltoAll 在多数拓扑中与基线接近，部分拓扑可获得更高带宽。同时，FTACAS 的合成时间显著低于基线，可取得平均约3个数量级的加速比，具备更好的工程可用性。

（3）提出了面向张量并行训练的计算通信并行优化方法，并在 TP/DP 混合并行配置下验证端到端收益。针对 Megatron 张量并行方法中同步通信阻塞明显、易造成算力空闲的问题，本文通过算子等价拆分与调度重排，将 AllReduce、ReduceScatter、AllGather 等通信尽可能移入可与矩阵计算并行的时间窗口，并在不改变训练语义的前提下提升计算通信并行度。基于 PyTorch 接口完成实现后，在混合并行训练配置下进行了实验验证。结果表明，该方法在多种模型规格上均能获得约1.25×–1.29× 的端到端加速，对应训练时间降低约20\%–22\%。Profiling结果显示，通信引起的计算资源空闲得到了有效缓解，整体训练迭代时间明显缩短。

\noindent \textbf{关键词：}分布式训练；集合通信；拓扑感知；张量并行；计算通信并行
