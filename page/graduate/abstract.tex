\chapternonum{摘要}

近年来，深度学习在计算机视觉、自然语言处理与科学计算等领域持续发展，训练数据量与模型规模不断增长。受限于单设备算力与存储容量，多节点集群的分布式训练逐渐成为主流方案。在分布式训练过程中，各计算节点一般通过集合通信操作完成参数、梯度及中间激活值等信息的同步与交换，常用集合通信算子包括 AllReduce、AllGather、ReduceScatter 与 AlltoAll 等。随着节点规模扩大与并行策略复杂化，集合通信愈发频繁且单次通信时间延长，通信开销成为端到端训练效率的重要制约因素。与此同时，现代训练集群通常由多种链路与多级分层结构组成，链路带宽与静态时延差异显著，现有通信算法在复杂互连环境下往往难以充分利用链路并行能力，容易出现通信轮数偏多、跨层链路负载不均以及调度灵活性不足等问题。除通信算法本身外，通信与计算在训练流程中的耦合关系同样影响整体性能，例如在张量并行训练中，通信操作与矩阵计算存在紧密数据依赖，容易造成计算资源空闲。围绕上述问题，本文从
面向真实物理拓扑的集合通信算法优化设计、
集合通信算法自动合成
以及
张量并行下的计算通信并行三个层面展开研究，以提升分布式训练的通信效率与整体吞吐。本文主要工作如下：

(1)针对存在双向环形链路的物理系统中经典环形算法传输能力利用不足、通信轮数偏多的问题，设计了具有链路聚合特性的双半环集合通信算法。
该方法通过数据块动态拆分、双向链路并行传输以及分阶段传输流程优化，将环形拓扑的双向链路容量进行有效聚合，在减少通信轮数的同时提升带宽利用率，并在此基础上给出了AllGather、ReduceScatter与AllReduce的统一实现方式。
该方法在昇腾 910C 集群上进行了实现与评估，结果表明在不同节点数与数据量配置下，双半环算法相对双向环算法带宽提升 2.7\%–33.1\%，能够在多种节点规模场景下获取显著收益。

(2)针对多级交换机拓扑中人为设计算法难以兼顾性能与适配性，现有算法自动合成方法又难以兼顾性能和求解效率的问题，构建了交换机拓扑感知的集合通信算法自动合成方法 FTACAS。
该方法以时间扩展网络为建模基础，统一刻画设备与交换机节点、链路带宽与时延以及转发机制，并在此之上设计事件驱动的贪心合成框架，通过基于贪心算法的数据块与链路动态匹配实现集合通信算法的自动合成，在短时间内合成高性能的通信方案。
% 适用于AllGather与AlltoAll 算子。
% 对多种典型 GPU 集群拓扑的实验结果表明，
基于多种典型 GPU 集群拓扑配置的仿真实验结果表明，
FTACAS 合成的集合通信算法的算法带宽整体优于对比基线 TECCL，在部分复杂拓扑上 AllGather 可达到基线的 1–3 倍；AlltoAll 在多数拓扑中与基线接近，部分拓扑能够达到基线的 1.5 倍。同时，FTACAS 的合成时间显著低于基线，平均可获得约 3 个数量级的加速比，提升了该方法在工程场景中的可用性。

(3)针对张量并行训练中同步通信阻塞明显、易造成计算资源空闲的问题，提出了面向张量并行训练的计算通信并行优化方法。该方法通过算子等价拆分与调度重排，将张量并行过程中的AllReduce通信调度到可与矩阵计算重叠的时间窗口内，在保证训练过程等价的前提下提升计算通信并行度。
% 该方法基于 PyTorch 接口完成实现并在
混合并行场景下的实验验证结果表明，该方法在多种模型规格上可获得 1.25×–1.29× 的端到端加速，对应训练时间降低 20\%–22\%，有效缓解了通信引起的计算资源空闲问题，明显缩短了训练迭代时间。

\noindent \textbf{关键词：}分布式训练；集合通信；链路并行；算法合成；计算通信并行
