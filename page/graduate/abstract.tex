\chapternonum{摘要}

近年来，随着深度学习模型规模的持续扩大，单设备的算力与存储容量已难以满足大规模模型训练需求，基于多节点集群的分布式训练逐渐成为主流方案。在分布式训练过程中，各计算节点通过 AllReduce、AllGather、ReduceScatter 与 AlltoAll 等集合通信操作完成参数、梯度及中间激活值等信息的同步与交换。随着节点规模扩大与并行策略复杂化，集合通信愈发频繁且单次通信时间延长，通信开销成为端到端训练效率的重要制约因素。与此同时，现代训练集群通常由多种链路与多级交换机组成，链路带宽与时延差异显著，现有通信算法在此类复杂拓扑下往往难以充分利用链路并行能力，容易出现通信轮数偏多、负载不均等问题。此外，计算与通信在训练流程中的串行依赖关系使得通信时间占据关键路径，造成计算资源空闲，影响整体训练效率。
围绕上述问题，本文从

(1)针对分布式训练集群中双向环形链路场景下经典环形算法传输能力利用不足、通信轮数偏多的问题，提出了具有链路聚合特性的双半环集合通信算法。
该方法提出了双半环通信模式，引入了分阶段传输流程优化与数据块动态拆分机制，将环形拓扑的双向链路容量进行有效聚合，在减少通信轮数的同时提升带宽利用率，并在此基础上给出了AllGather、ReduceScatter与AllReduce的统一实现方式。
该方法在物理集群上进行了实现与评估，结果表明在不同节点数与数据量配置下，双半环算法相对双向环算法带宽提升 2.7\%至33.1\%，能够在多种节点规模场景下获取显著收益。

(2)针对分布式训练集群中多级交换机拓扑场景下人为设计集合通信算法难以兼顾性能与适配性，现有算法自动合成方法又难以兼顾性能和求解效率的问题，提出了交换机拓扑感知的集合通信算法自动合成方法 FTACAS。

\chapternonum{Abstract}

In recent years, deep learning has advanced rapidly, with training data volumes and model scales growing continuously. Constrained by single-device computational power and memory capacity, distributed training across multi-node clusters has become mainstream. During distributed training, compute nodes synchronize parameters, gradients, and activations through collective communication operations such as AllReduce, AllGather, ReduceScatter, and AlltoAll. As cluster scales expand and parallelization strategies become more complex, communication overhead has become a significant bottleneck for training efficiency. Meanwhile, modern clusters typically consist of diverse links and multi-level hierarchical structures with significant bandwidth and latency variations. Existing algorithms often fail to fully exploit link parallelism, leading to excessive communication rounds and unbalanced loads. Additionally, the coupling between communication and computation affects overall performance; for instance, in tensor parallelism, communication exhibits tight data dependencies with matrix computations, causing compute resources to idle. This thesis conducts research from three perspectives: collective communication algorithm optimization, automatic algorithm synthesis, and computation-communication parallelism, aiming to improve communication efficiency in distributed training. The main contributions are as follows:

(1) To address underutilization of transmission capacity and excessive communication rounds in classical ring algorithms on systems with bidirectional links, we design a double half-ring collective communication algorithm with link aggregation. This method aggregates bidirectional link capacity through dynamic data chunk splitting, parallel transmission, and phased workflow optimization, reducing communication rounds while improving bandwidth utilization, with unified implementations for AllGather, ReduceScatter, and AllReduce. Evaluation on an Ascend 910C cluster shows 2.7\%–33.1\% bandwidth improvement over the bidirectional ring algorithm across different configurations.

(2) To address the difficulty of balancing performance and adaptability in multi-level switch topologies, we develop FTACAS, a switch-topology-aware automatic collective communication algorithm synthesizer. Using time-expanded networks as the modeling foundation, it uniformly characterizes devices, switches, link properties, and forwarding mechanisms. An event-driven greedy synthesis framework achieves automatic algorithm synthesis through dynamic matching between data chunks and links. Simulations on typical GPU cluster topologies show that FTACAS achieves 1$\times$-3$\times$ the baseline TECCL performance for AllGather and up to 1.5× for AlltoAll, while reducing synthesis time by approximately three orders of magnitude.

(3) To address synchronous communication blocking in tensor parallel training, we propose a computation-communication parallelism optimization method. Through operator equivalent splitting and schedule reordering, AllReduce communication is scheduled into time windows overlapping with matrix computation, improving parallelism while ensuring training equivalence. Experiments in hybrid parallelism scenarios show 1.25$\times$–1.29$\times$ end-to-end speedup, corresponding to 20\%–22\% reduction in training time.

\noindent \textbf{Keywords:} Distributed Training; Collective Communication; Link Parallelism; Algorithm Synthesis; Computation-Communication Parallelism
